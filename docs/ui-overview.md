# 主要界面说明

DotCanvas 的 Web 控制台挂载在 `/ui` 下。打开站点根路径 `/` 后会重定向到守护进程页。界面支持中英文切换。

## 画布工作台（Canvas Studio）

路径：`/ui/canvas`

用来创建与编辑画布内容：

- **选择 / 创建画布**：从列表打开已有画布，或输入名称新建。每个画布对应 `canvas/<画布ID>.py`。
- **编辑视图构建函数**：为每个视图编写 Python 函数体，返回值决定该元素的类型、位置与样式。
- **预览参数**：在「预览参数」中填入 JSON 对象（例如 `{"start_date": "2025-09-01"}`），刷新预览时会传给所有视图构建函数。
- **实时预览**：保存后或点击「刷新预览」会渲染 296×152 的预览图。未保存的代码不会出现在预览中。
- **快捷键**：`Ctrl/Cmd + S` 保存当前画布。

适合日常设计画面、调试动态内容与检查布局。

## 守护进程控制（Daemon Control）

路径：`/ui/daemon`

监控向 Dot. 设备推送画面的后台调度器：

- 查看守护进程是否在运行、任务数量与启动时间。
- 启动 / 停止 / 重启守护进程。
- 浏览已注册的计划任务（下次执行、上次执行、参数等）。
- 查看近期服务日志。

修改配置页中的设备或 Cron 后，通常需要在此重启守护进程使新任务生效。

## 配置管理（Config Manager）

路径：`/ui/config`

编辑服务端 `configs/config.yaml` 中的内容：

- **API 密钥**：在 Dot. App 中生成。
- **设备**：设备昵称与设备 ID。
- **计划任务**：任务名、画布 ID、Cron 表达式、可选 JSON 参数、是否暂停。
- **立即执行**：对已保存的任务点击「立即执行」，可立刻推送一次（使用已保存参数）。

任务里的 **参数** 会在渲染画布时传入视图构建函数，详见 [视图脚本进阶用法](view-scripts.md)。

## API 令牌（API Tokens）

路径：`/ui/tokens`

为自动化集成创建与吊销 Bearer 令牌。令牌明文仅在创建时显示一次。具体端点说明见 [API 系统](api-system.md)。

## 文档（Docs）

路径：`/ui/docs`

在浏览器中浏览本仓库 `docs/` 下的 Markdown 文档（本页即其中之一），便于在部署环境中直接查阅界面说明与视图脚本用法，无需单独打开仓库。
